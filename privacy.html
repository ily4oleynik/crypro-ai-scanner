Privacy Policy / Политика конфиденциальности

Last updated: 2026-09-28

1. Operator

Сервис Crypto AI Scanner («мы»). Контакт по вопросам данных: через Telegram-каналы на сайте или email, указанный в канале. Юридическое лицо / ИП будет указано после регистрации бизнеса и подключения платежей.

2. What we process

  • Email и хеш пароля (аккаунт)
  • Telegram id / chat id (если вход или привязка бота)
  • История сканов, watchlist, алерты, выбран
  • Email waitlist (если оставили)
  • Технические логи: IP, User-Agent (ограниченно, для rate limit и безопасности)
  • localStorage: JWT, язык, локальная история риска на устройстве

3. Processors / third parties

  • Hosting: Railway (или аналог)
  • Market data: DexScreener
  • Security flags: GoPlus
  • AI text: Groq / OpenRouter (промпт содержит факты скана, не пароли)
  • Telegram Bot API (алерты, login widget)

4. Purpose

Предоставление сканов, аккаунта, алертов, waitlist. Мы не продаём персональные данные.

5. Exchange API keys (Bybit)

Ключи передаются на сервер только для запроса, который вы инициируете. Текущая сборка не предназначена для долгого хранения ключей. Не передавайте ключи с правом вывода средств.

6. Retention

Аккаунт и связанные данные — пока аккаунт существует. Удаление: запрос через контакты выше. Логи — краткосрочно.

7. Your rights

Запрос на доступ / исправление / удаление данных аккаунта. Cookies: используем localStorage для сессии и настроек; отдельный cookie-banner может появиться позже.

8. Security

HTTPS, хеширование паролей, rate limits. Абсолютной безопасности не гарантируем.
